# 🚗 计算机视觉课程作业：车道线检测可视化系统

## 项目介绍
本项目基于《计算机视觉检测》课程核心知识点，实现了完整的车道线检测流程，并通过Streamlit实现了全流程可视化交互。

## 涵盖的课程知识点
1. **图像预处理**：高斯模糊去噪
2. **图像二值化**：大津法（Otsu）自动阈值、手动阈值
3. **边缘检测**：Canny边缘检测算法
4. **特征检测**：霍夫变换（普通霍夫、改良霍夫）
5. **ROI感兴趣区域**：只保留图像下半部分，排除背景干扰
6. **性能分析**：算法耗时对比、加速比计算
7. **数据可视化**：Matplotlib性能图表、Streamlit全流程展示

## 项目功能
### 后端功能
- 图像预处理（高斯模糊）
- 二值化（Otsu/手动阈值）
- Canny边缘检测
- 普通霍夫变换车道检测
- 改良霍夫变换车道检测（分块跳变检测优化）
- 性能对比测试（耗时、加速比）

### 前端功能
- 图片上传、展示、下载
- 视频上传、处理、下载
- 侧边栏参数实时调节（含鼠标悬停解释）
- 分步骤可视化：原图→模糊→灰度→二值化→边缘→ROI→结果
- 两种算法对比展示
- 性能对比图表
