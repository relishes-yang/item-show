
# 🔌 智能电力仪表检测系统（高级版）

基于计算机视觉和OCR技术的智能仪表读数识别系统，支持自动识别量程、单位、多仪表检测。

## ✨ 核心特性

### 1. 智能自动识别
- ✅ **自动量程识别**：通过OCR读取刻度数字，自动确定量程范围
- ✅ **自动单位识别**：识别 MPa、kPa、A、V 等单位
- ✅ **自动角度计算**：根据刻度位置自动计算角度范围
- ✅ **多仪表检测**：单张图片支持检测多个仪表

### 2. 可视化处理流程
- 🔬 **步骤1**：图像预处理（灰度化、增强、边缘检测）
- 🔬 **步骤2**：仪表区域检测（霍夫圆变换）
- 🔬 **步骤3**：刻度OCR识别 + 指针检测
- 🔬 **步骤4**：最终结果可视化

### 3. 高精度识别
- 使用 **EasyOCR** 进行中英文刻度识别
- 自适应阈值处理分离指针
- 基于几何关系的精确角度计算
- 线性插值计算最终读数

## 🚀 快速开始

```bash

```

## 📖 使用说明

### 上传图片
支持 JPG、PNG、BMP 格式，建议：
- 图片清晰，光线均匀
- 仪表正对摄像头，避免严重透视畸变
- 指针与表盘对比度明显

### 自动检测流程
1. **预处理**：系统自动增强图像对比度，检测边缘
2. **区域检测**：自动识别所有圆形仪表区域
3. **OCR识别**：读取刻度数字和单位
4. **指针检测**：精确定位指针角度
5. **读数计算**：根据角度和量程计算最终读数

### 结果展示
- **处理步骤**：标签页形式展示每步处理结果
- **可视化标注**：绿色圆圈（表盘）、蓝色直线（指针）、黄色圆点（刻度）
- **仪表盘**：每个仪表独立的可视化仪表盘
- **数据表格**：所有仪表的详细参数和读数
- **CSV导出**：支持导出检测数据

## 🧠 核心算法流程

```
输入图像
    ↓
[1] 预处理（CLAHE增强 + Canny边缘检测）
    ↓
[2] 霍夫圆变换检测仪表区域
    ↓
[3] 对每个仪表：
    ├── [3.1] ROI提取
    ├── [3.2] EasyOCR识别刻度和单位
    ├── [3.3] 自适应阈值 + 霍夫直线检测指针
    └── [3.4] 几何计算角度和读数
    ↓
[4] 结果可视化与导出
```

## 📊 识别精度优化

### 如果OCR识别不准确：
1. **提高图片分辨率**：建议仪表直径 > 200像素
2. **改善光照**：避免反光和阴影
3. **调整相机角度**：尽量正对仪表拍摄

### 如果指针检测不准确：
1. **增强对比度**：确保指针颜色与表盘有明显差异
2. **清洁表盘**：去除污渍和划痕
3. **调整参数**：在代码中修改 `adaptiveThreshold` 参数
